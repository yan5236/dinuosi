# 调色设计与实现边界

## 操作与布局

依据 2026-10-14 对剪映和 Resolve 的现场研究及截图（本地 `.local/color-research/`）。采用剪映的片段级集中面板，采用 Resolve 的串行校正、独立旁路、颜色选区和信号检查。专业性来自可控的处理与可验证的结果；不宣称具备 Resolve 的完整色彩管理能力。

选中图片或视频后，右侧检查器显示“调色”页签，音频与空选择隐藏该入口。默认“基础”提供曝光、对比度、色温、色调、饱和度、自然饱和度、高光、阴影、白色、黑色；曝光单位为 EV，其余以零为中点。滑块实时预览，释放保存一次；数值可直接输入，失焦或 Enter 提交，Esc 取消。参数改动只作用于检查器主片段，复制/粘贴将整套调色应用到选中且未锁定的画面片段，不修改音频或源文件。

面板顶部使用现有灰阶拨片、复制/粘贴文字与重置图标，工具导航采用统一等宽页签。基础页按“曝光与明暗”“色彩平衡”组织六个常用参数；高光、阴影、白色、黑色放在曝光/对比度下方默认收起的“明暗细节”，折叠入口用方向箭头、整行命中与悬停底色标明状态，支持 Enter/空格。色温和色调轨道用低饱和渐变标识方向。底部“校正步骤”按需展开管理区，默认只有 01，可添加至八个，按编号从左到右串行处理；每一步可独立启用、重置、删除。工具页为基础、HSL、曲线、色轮、局部。无需操作节点连线即可完成一般校正，多步骤允许分别处理曝光、肤色/物体颜色与风格。

HSL 提供八个色组，各自保留色相、饱和度与亮度，重叠区域平滑混合。曲线区显示输入→输出网格及总/R/G/B 通道，点击加点、拖动修改、右键删除内部点；端点可纵向移动。阴影、中间调、高光三色轮并排显示，亮度控制位于各轮下方，精确色偏按需展开当前轮的 X/Y；零值保持中性。局部工具限定当前步骤，默认只显示蒙版和颜色范围两个开关，启用后展开：矩形/椭圆蒙版支持位置、大小、旋转、羽化、反转；颜色限定器支持连续环状色相范围、边缘柔化、最低饱和度及亮度范围。两种选区同时启用时相乘，限制调色而不裁掉原画面。

HSL 的三条轨道随当前色组显示连续语义渐变：色相为邻近颜色、饱和度为灰色到彩色、亮度为暗色到浅色。吸管暂停播放并从实际预览画布取样，为当前步骤建立一个独立取样色组，原八色参数保持不变；取样色组显示在吸管旁，可重新取样更换中心色相并保留其 H/S/L 参数及动画。留白、透明和无色像素不产生任意色相，Esc、再次点击吸管或开始其他编辑退出。取样不会改选或拖动片段，不读取屏幕或源文件，不新增后台解码；仅取样期间保留一帧 CPU BGRA 像素，取消或成功后释放。独立色组以取样色相为中心，在 60 度内平滑衰减，作为固定八色调节之外的独立增量；预览和导出共用，不宣称复制剪映的内部算法。

示波器开关位于调色面板底部，显示最终时间线画面的 RGB 直方图与亮度波形；数据来自实际合成像素，后台统计，关闭不计算。不添加副标题、教程、项目名或状态装饰文字，保持灰阶品牌和现有输入风格，小窗口可滚动。

## 数据与渲染

Core 保存片段级调色后备值及有序步骤。V1 项目可选 `color` 缺失时保持中性，加载与修改拒绝非有限数、非法范围、步骤超限和不合法曲线。基础、HSL、三色轮 X/Y/亮度、蒙版数值及颜色选区数值复用片段 `keyframes`，磁盘类型为 `color/<步骤索引>/<参数身份>`；错误步骤或控件身份拒绝加载。参数右侧菱形保存实际当前值，空/实心表示当前帧是否有节点，两帧以上提供前后导航；调色操作与关联选择中的检查器主画面绑定，不给关联音频添加调色动画。已有动画时修改遵守全局自动加帧偏好：开启时在实际改值后添加，关闭时在帧间整体偏移该参数；无动画时修改静态值。

`Clip::color_at` 使用同一贝塞尔关键帧求值、范围夹紧与端点保持，检查器、预览及导出共用。独立关键帧曲线面板列出已启用动画的调色参数，以步骤和所属组区分同名控件，支持既有预设、节点与切线编辑。亮度选区交叉时将最终两端归一化成有序范围。片段复制/分割和换帧率沿用现有关键帧时间规则；追加步骤保留动画，重置单步清除该步动画，删除步骤清除其动画并重映射后续步骤身份，全局重置清除全部调色动画。撤销、重做、保存失败回滚复用现有时间线事务。调色面板复制的是当前播放头调色快照，粘贴替换目标静态调色并清除其旧调色动画；片段复制仍保留完整动画。

处理顺序：每步按输入颜色和素材局部坐标求选区 → 白平衡/曝光/明暗 → 色轮 → 饱和度/HSL → 总曲线及 RGB 曲线 → 按选区混合。步骤间用浮点 RGB，输出前才量化为 BGRA；alpha 不变。曝光按 sRGB 传递函数转换到线性光乘以 2^EV，其他工具在显示 RGB 上运算。sRGB 传递函数参考 [W3C CSS Color 4](https://www.w3.org/TR/css-color-4/#color-conversion-code)。曲线采用有界分段线性插值，避免超调，不声称复制其他软件算法。

预览和原尺寸导出共用同一处理函数，调色先于镜像/缩放/旋转与轨道合成；预览透明补边不参与蒙版坐标，局部尺寸按有效源画面归一化。中性/整套旁路直接借用源帧，参数更新继续复用解码缓存，不重解码源文件。

## 当前范围

当前运行时是解码后的 8 位 SDR BGRA；浮点调节不会恢复源端已截断的动态范围。颜色输入/输出曲线控制点和功能开关仍是静态属性。尚不支持 HDR/Log/ACES/OCIO、输入输出色彩空间选择、LUT、自动跟踪、调节轨道、平行/混合节点及持久个人预设；吸管仅针对本软件预览画布。复制/粘贴是会话内复用，保存/重开保留片段调色及数值关键帧。上述功能需要分别完善媒体色彩元数据或时间线契约后再接入，不提供无效果按钮。

## 验收

验证中性逐像素一致、整套/单步骤旁路、灰度、色相环绕、曲线边界、色輪分区、蒙版移动/反转/羽化、限定器选红不选绿、alpha 保留、非法数据拒绝、旧项目兼容、持久化、撤销、锁定跳过以及预览/导出共用结果。GPUI 检查滑块、输入、步骤切换、数值关键帧、导航、关联主对象和窄窗口布局；真实程序用隔离数据目录与 Computer Use 输入操作，WGC 超时时使用只读窗口像素截图，检查实际画面和保存结果。
