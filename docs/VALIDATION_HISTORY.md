- 新运行库下重跑既有真实导出回归，H.264 硬件/软件、MPEG-4、源音轨/MIDI、裁剪/变换/动画、取消、坏源/缺源、已有文件保护均通过。466 项 Windows Rust 运行依赖许可清单重新收集，阻断项为零；既有五个上游未提供独立许可原文的声明材料及完整源码仍按原约定保留。缺失源码、AOM 版权、VPX 专利声明、Rust 许可、运行库哈希不符及审计过期六项拒绝边界通过。
