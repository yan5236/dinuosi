# 文本与手动字幕

左侧素材区“文本”分类提供“普通文本”和“手动字幕”两项，在播放头创建三秒片段，自动建轨、选中并聚焦正文。普通文本居中，字幕默认位于画布下方；两者均为白字、默认关闭描边。可直接修改中文/英文多行正文；正文框支持输入法组合、字素删除、选择、剪贴板与自动折行。正文实时更新预览和片段标签，失焦时保存并记录一次撤销，Esc 取消本次正文编辑。关闭窗口前也会提交正文；校验或保存失败时保留窗口和输入草稿，可重试或取消。

检查器提供起止帧时间码、系统字体系列、字号、粗体、斜体、左右/居中对齐、RGB 颜色、描边宽度与颜色、文字框宽度和行距。字体下拉以独立滚动浮层显示，不推动或滚动检查器正文。点击颜色块打开 HSV 调色器，拖动实时预览，点击外部或 Enter 保存一次，Escape 恢复原色；旁边保留六位 RGB 精确输入。阴影支持颜色、强度、模糊和 X/Y 偏移，背景支持颜色、强度、内边距与圆角。描边、阴影与背景都有独立开关，启用后才展开参数；描边开启时从 2 像素开始，关闭使用零宽度并保留颜色。新建默认关闭，已有项目或继承、预设中的样式不改写。位置、缩放、旋转、不透明度及其关键帧复用既有检查器与画布手柄。宽度按项目像素控制自动折行，行距为字号倍数。超出画布高度的正文按文字框裁切。

字幕具有独立于轨道和片段的组 UUID。选中字幕后再新增，沿用其组、样式和静态变换；其他情况下新增独立字幕组。检查器中的“应用到本组字幕”默认开启，仅对之后的排版修改生效，不会因开关本身覆盖已有局部样式。关闭时仅修改当前句。正文、起止时间和几何变换始终单句生效；组内有锁定片段时整次批量样式修改拒绝，显示实际错误。

全局“字幕”检查器独立于单句排版页签，跨组按开始时间排序，显示正文与起止时间；仅在无片段选择或当前检查器主对象是字幕时显示该页签；选中图片、视频、音频或普通文本时隐藏，并将原字幕页回退显示为当前对象的基本检查器。多选依据最后点击的主对象判断。列表占据剩余高度，点击正文直接编辑，前后导航同步时间线选择、检查器主对象和播放头。每句提供删除，锁定句禁止编辑和删除；删除主对象后定位相邻字幕，最后一句删除且无剩余片段选择时保留全局列表，删除可撤销。列表新增仍跟随播放头，选中字幕时沿用其组。正文外部点击、删除和撤销前先提交当前输入，防止旧会话在失焦后覆盖后续操作。新增、移动或延长发生重叠时沿用同类轨道分流规则，不覆盖、删除或自动顺延其他句子；分轨不会拆散字幕组。

Core `text.rs` 定义正文、样式、分组与编辑约束；`text_render.rs` 用锁定的 COSMIC Text 0.14.2 和系统字体回退生成透明 BGRA。优先使用真实斜体；斜体字形缺失时重新使用正常体并合成 14 度倾斜，避免中文因没有斜体字体而显示缺字方块。预览、画布命中与原尺寸导出共用相同排版结果及变换。缓存按最近使用淘汰、合计最多 64MiB，不限制条目数，单幅最多 16M 像素。首次使用延迟扫描字体；字体文件不会复制到项目，跨机器重开时可用字体差异可能改变排版。

生成文字使用 `MediaKind::Text`，普通文本与字幕分别进入 Text/Subtitle 轨道，不伪造磁盘媒体源，不参与声音解码、倒放或变速。文本以 V1 可选 `text` 字段保存，旧项目没有字段时保持原媒体行为；非法正文、样式、轨道职责和字幕身份拒绝载入。裁边、移动、切割、删除、锁定、隐藏、轨道重排、撤销/重做与保存重开均沿用既有时间线事务；移动和右裁边按文字结束帧夹紧到一天上限，多选移动保留相对间距。

“保存样式”保存命名的字体、排版、描边、阴影与背景，不保存正文、时间、位置或字幕组。用户级 `text-presets.json` 与项目、通用偏好分开，复用原子写入；最多 100 项，重名不覆盖。左侧“文本”分类的“我的样式”显示实际效果缩略图：选中文字时应用到当前样式范围，无文字选择时创建带此样式的普通文本。删除预设不影响已应用的片段，字体文件不随预设分发。

左侧“文本”分类提供 SRT 导入及当前字幕组导出。导入支持 UTF-8（含 BOM）、CRLF、多行和重叠句，整体成功才提交一条历史；每次导入建立独立字幕组，保留原有时间线内容。毫秒四舍五入到最近项目帧，短句至少一帧。常见 b/i/u/font 标签转为纯正文；原有格式效果不导入。文件最多 4MiB、一万条，每句最多 4096 字符，时间限一天。导出按时间排序、重新编号并生成 UTF-8 SRT；不包含字体与艺术字效果，不覆盖已有文件。SRT 无法表示的空句/正文空白行返回错误，不静默遗漏。

本次支持普通文本、手动字幕、艺术字基础效果、用户样式预设、SRT 交换与视频烧录。自动识别、LRC/ASS、复杂模板、渐变/立体、富文本逐字样式和高级动画尚未接入；当前不嵌入或分发系统字体。
