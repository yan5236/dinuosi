# 架构说明

时间线左右/上下镜像切换选中且未锁定的图片、视频片段，两个轴独立，再次点击恢复。镜像保存在片段变换中，默认关闭，旧项目缺失字段时沿用原画面；预览和导出共用源像素反向采样，保持缩放、位置、旋转及关键帧不变，并沿用单次撤销和保存事务。

GUI 是人类接口，CLI 是脚本接口，MCP 是 AI 接口，Action 是自动化接口，Plugin 是扩展接口；它们下面共享的始终只有一个 Dinuosi Runtime。

产品目标与已确认约定以版本控制内的 [RPD.md](RPD.md) 为准；本地 `.ref/` 仅保留历史参考。当前已实现剪辑、预览和导出，CLI、MCP、Action、插件运行时与统一任务系统尚未实现。

```text
apps/desktop (GPUI + 窗口会话)
    ├── dinuosi-command → dinuosi-core
    ├── dinuosi-core (媒体模型、探测、帧提取、流式解码、离线状态)
    │       └── dinuosi-media → 原生桥接库 → 受控 libav 动态库
    ├── dinuosi-icons
    └── dinuosi-cursor (Windows 原生光标 FFI)
assets/brand → 编译嵌入 Desktop
```

当前仅建立有实际代码职责的六个 package，媒体 FFI 与原生光标 FFI 各自独立于 Core/Desktop。设计文档建议的 9–12 个主要 crate 将随媒体、渲染、任务等模块实际落地逐步建立，不提前添加空壳。

## 当前边界

- Core 定义项目模型和稳定 UUID，并通过版本化存储保存元数据及源素材路径引用。`media.rs` 提供媒体模型、类型/时长探测、BGRA 帧提取和离线恢复检查；`media_stream.rs` 提供固定内存的视频帧与 PCM 流式解码及原生会话清理。不依赖 GPUI、Rodio 或音频设备，CLI 可直接调用这些公开接口；不直接序列化内部结构。
- Core 的 `ProjectStore::import_media` 统一批量探测、去重、逐项失败反馈和原子保存引用；`load_media` 统一重开探测、别名与离线保留。`rename_media` 保存显示别名，`remove_media` 仅移除路径引用；均不改写源素材并在索引失败时恢复项目。Desktop 文件选择器和拖放均调用同一导入接口。
- Command 将项目生命周期操作委派给 Core；本层不实现磁盘读写，也不依赖 GUI。
- Desktop 保存当前窗口的导航、素材解码结果、预览选区、音量、标尺缩放、框选和指针状态；项目及源路径引用由 Core 原子保存。导入不复制源文件，重开项目重新探测路径，失联引用保留为离线素材。
- Desktop 的 `view.rs` 负责会话与项目管理，`editor.rs` 负责剪辑区域和比例布局，`ui.rs` 提供灰阶与窗口操作。`library.rs` 管理引用式素材库，`media.rs` 只将 Core 元数据和 BGRA 像素适配为 GPUI 图像，`playback.rs` 消费 Core 解码器并通过 Rodio 输出声音、维护设备播放时钟，预览会话/绘制与指针交互各自独立；不引入 WebView，也不修改 GPUI。
- Icons 不依赖 GPUI；以素材 `spec.json` 为来源，在 `OUT_DIR` 生成类型化枚举、中文标签、逻辑资源路径及原始 SVG 内容。
- Cursor 不依赖 GPUI 或媒体，校验窗口所属线程与像素输入，将现有 Razor SVG 栅格结果创建为 Windows 原生光标；仅在时间线内容区处理系统光标消息，保留 GPUI 的窗口移动、尺寸和输入处理。窗口关闭或会话释放时移除回调并销毁私有光标；Core/Desktop 继续禁止 unsafe。
- GPUI 的 AssetSource 提供内嵌 SVG 与 PNG；SVG 使用 GPUI 单色渲染并由界面文字色着色，双色 Logo 使用原始 PNG 保留品牌色。

## 时间线与媒体实现

Core `timeline_playback.rs` 统一片段源帧映射：`reversed` 在当前裁剪选区内倒序，`freeze_frame` 固定绝对源帧且优先于方向。定格仅用于视频，保留时长与动画，停止该段原声，再次点击取消；片段外播放头取最近首尾画面。预览与导出共用映射，倒放裁边及切割保留剩余画面的源帧连续性，改变项目帧率同步换算定格帧。V1 字段缺失默认正放、无定格，非法源帧及类型拒绝载入。

倒放 PCM 由 `media_reverse.rs` 从尾部按最多一秒解码，按立体声采样对逆序，保留左右声道、音量动画、取消及错误报告；内存不随片段长度增长。Desktop 波形按实际源时间查询。导出倒放帧逐帧重新寻址，保持原尺寸且只保留当前画面，长片段可能增加导出耗时。工具栏撤回/还原复用 `History` 和保存失败时的反向回滚；检查器用独立页签切换基本/项目、标记点与变速，空选择及仅选中图片时隐藏变速。

Core `speed.rs` 将源选区与项目时长分开保存：常规倍率为 0.1–100，视频曲线为源进度上的 0.1–10 倍分段线性控制点。倍率倒数的解析积分决定时长，解析反解用于预览、导出、波形和音频寻址。慢放裁剪、分割保留亚帧源边界，倒放沿相反源方向消费；修改速度保持源选区，同轨后续片段随时长差移动，其他轨道保持位置。锁定后续片段、时间越界或关键帧折叠拒绝整次修改；画面/音量关键帧按新旧片段时长比例换算。

`media_speed.rs` 包装普通、倒放及 MIDI 的固定格式 PCM。声音变调关闭时，常规和曲线共用 `media_curve.rs` 的固定窗 WSOLA：每次至多 512 对输出按片段源时间映射寻址，在前后 256 对范围匹配双声道相位并重叠相加，源缓存最多 4096 对。短选区缩小半窗，窗口起点夹紧到可用源范围，避免滤镜提前 EOF 或搜索补零区域造成尾音缺失。开启变调时成对线性重采样；两条路径均保留固定内存上限及取消/错误句柄，无需新增媒体桥接口。V1 磁盘契约显式保存精确源区间、倍率、曲线和变调开关，旧项目缺字段沿用 1 倍。Desktop `speed_inspector.rs`、`speed_input.rs`、`speed_curve.rs` 复用输入、拨片和根节点手势，拖动中只预览，释放后保存一次；新控制点两侧保留至少 0.001 源进度，旧密集点仍可纵向调速，横坐标保持原值。小窗口内容可滚动，重置按钮固定在底部。音频队列耗尽时精确停止在项目终点，避免非整秒设备时钟的舍入导致播放状态悬停，EOF 同步提取尾部解码诊断。

当前已先按界面任务接入素材导入与预览，时间线已由 Core 的 `timeline.rs` 定义整数帧/帧率、稳定 UUID、轨道、片段、变换和历史；`timeline_file.rs` 将其显式映射为可选 V1 字段，旧项目缺失时创建空轨道。插入、移动、裁边、分割、删除和参数修改都通过核心接口，桌面在一次编辑事务完成时保存并记录一条历史。导出边界见下文及 [导出实现与验证](EXPORT.md)。

项目保存使用独立 `ProjectFormatV1`、版本标识和迁移入口，不直接序列化内部模型。EditorSession 和 Preferences 与项目内容分离。

Desktop 后台任务调度 Core 的媒体探测、寻址与源路径检查。Core 解码器只保留最新 BGRA 帧，通过 PCM 迭代器输出立体声 48kHz 样本，销毁时设置取消标志、等待后台线程并释放原生上下文；Desktop 回收 GPU 纹理并输出声音。当前解码画布固定 640×360、24fps；Core 提供计入像素比例和旋转的有效画面尺寸，Desktop 移除透明补边后再按面板比例适配，不代表最终导出质量。`midi.rs` 使用 RustySynth 与编译嵌入的 MIT FluidR3 GM 音源解析和采样合成标准 MIDI，直接接入共享 PCM 流，不经过 FFmpeg/ModPlug；256 复音、固定块缓冲，寻址在后台预渲染到目标点，成本随起点增长。共享媒体接口已可无头调用，CLI、Action、插件及 MCP 应用入口尚未实现。

## 素材接入记录

音频素材由 Core 的 `waveform.rs` 复用共享 PCM 解码器提取上下峰值，双声道保留极值以免反相抵消，每 16 个采样帧约 0.33ms，并按两两合并建立多级缓存。Desktop 的 `waveform.rs` 在导入、重开和离线恢复后串行后台提取，每个载入实例尝试一次，共享解码器依据 libav 返回码报告失败：可恢复坏包不导致波形丢弃或播放误报，真实解码错误保留详细诊断，没有 PCM 样本仍拒绝波形；会话缓存由素材预览、下方裁剪选区条和时间线共享，不保存到项目或复制源文件。各处使用青蓝色，每个可见设备像素按源时间区间查询峰值，结果按源缓存身份、起点、时长、尺寸和 DPI 缓存为 BGRA 纹理。播放头、悬停与窗口平移复用纹理，每处只提交一次图片绘制；裁边、滚动、缩放、源替换或尺寸/DPI 变化时重建，替换和元素移除时释放 GPU 图片。时间线计入源入点、水平滚动和当前缩放，最细缓存覆盖 1800px/s 上限。素材预览与裁剪条均显示完整源波形，裁剪条的选区边框、把手和播放头覆盖在波形上；时间线画面预览仍按项目画布合成。

轻线来源：`E:\轻线图标-64枚完整套装\qingxian-icons-88`。最初接入的 v1.5 清单为 89 枚，包含 `replace-media`；当前仓库清单为 v1.9，共 104 枚，以 `crates/icons/spec.json` 为准。原始轻线 SVG 保留 24×24 viewBox、1.8 描边、currentColor 和圆角端点/连接，播放头、实心关键帧及专用刀片光标使用填充图形。

本轮从 `.ref/qingxian-library-filters-5/svg` 接入全部、音频、动效、特效、`playhead-head` 及用户提供的 `warning` 三角感叹号，视频 SVG 与原文件相同。项目清单升级到 v1.6，当时共 95 枚。播放头采用原始实心填充，其余新增图标保持 1.8 描边。

Logo 来源：`E:\轻线图标-64枚完整套装\Dinuosi-Logo-Kit`。项目在 `assets/brand` 保留 PNG 导出文件与可编辑 SVG 原稿，界面采用主标志 PNG；本地参考素材放在不进入版本控制的 `.ref` 目录。

## 时间线与检查器边界

- `timeline.rs` 的编辑、约束、矩形选择、参数限值、刻度生成和撤销/重做不依赖 GPUI。检查器坐标是 1920×1080 默认项目画布中心的像素偏移，X 向右、Y 向下，旋转为角度。
- `composite.rs` 在后台解码各可见片段，使用源入点寻址，应用透明度/缩放/平移/旋转并按轨道顺序混合；会话级 `FrameCache` 仅保留当前可见视频源帧，位置、缩放、旋转和透明度更新复用解码，源帧/帧率/素材载入代次变化时失效，隐藏、离线及帧尾移除缓存。图片直接共享首帧，透明及不透明像素使用等价快路径；开发构建为 Core 启用优化以满足交互合成时延。`timeline_audio.rs` 按时间线的空隙、片段位置、源选区和静音状态混合 PCM。Desktop 的 `timeline_preview.rs`、`timeline_sound.rs` 仅做任务调度、图像上传、Rodio 设备与播放时钟适配。
- `timeline_state.rs`、`timeline_actions.rs` 保存 UI 手势并调用 Core；`timeline_view.rs`、`timeline_clip.rs` 与 `timeline_tracks.rs` 绘制刻度、片段、轨道头及滚动条，`timeline_drag.rs` 绘制缩略图光标。`inspector.rs` 沿用原生 TextInput 处理画面参数输入；`audio_inspector.rs` 对音频仅显示音量一个参数，沿用画面检查器的左侧 63px 标签、中间滑块和右侧 76px 深色数值框/上下箭头；音量显示一位小数 dB，支持直接输入、Enter/失焦提交、Esc 取消及每次 0.1dB 微调，默认 0.0dB、最低 -∞dB、最高 20.0dB。Core 保存有限线性增益（0 为静音，1 为默认，10 为最大），PCM 混合按片段增益生效；滑块有限区域为 -60 至 20dB，零端点完全静音，释放保存并记录单次撤销。旧项目缺少类型时按源文件探测或离线扩展名推断，原媒体/主轨音频自动迁移且默认单位增益。
- `TimelineSession.primary_clip` 保存最后点击的已选成员，仅用于检查器读取；时间线和预览点击均更新它，框选清除它，失效身份回退到首个已选片段。画面参数、音量和变速按主对象读取，变速仅修改其同类型选择；整组移动、裁边和切割仍使用完整选择集合，主对象不写入项目文件。
- `tooltip.rs` 为轨道头和时间线工具提供即时向下显示的纯文字气泡与指向控件的箭头，浮层越过轨道裁切；提示按操作及当前状态命名，与图标资源标签分离。支持鼠标悬停、Tab/Shift+Tab 聚焦和 Escape 关闭，不修改核心模型。
- `trim_handle.rs` 是素材预览与时间线共用的裁剪把手；把手在片段两端向外延伸 12px，时间零点在轨道头右侧额外预留 12px，右端也保留对应空间。刻度、播放头、拖入和框选采用同一时间原点；轨道头与内容使用相同的垂直裁切区。时间线在同一内容裁切区内先绘制全部片段，再绘制全部选中片段把手，使相邻素材不遮挡把手且鼠标优先命中裁边。
- 图片导入的 5 秒仅是默认放置时长，时间线左右裁边可超过该时长，且不修改源入点；保存和重开按图片类型允许延长。视频和音频仍受实际源时长限制；图片最短一帧、左侧不越过时间零点，时长遵守现有一天范围。
- 连续寻址串行消费完成的中间帧并追赶最新请求，避免每次移动都丢帧造成预览饥饿。`ScrubPreview` 默认 `Live`，设置窗口通用页可切换 `OnRelease`，作为用户偏好保存，不写入项目。
- `preview_geometry.rs` 按合成画布及素材有效尺寸计算旋转矩形和命中区域；`preview_transform.rs` 在时间线预览上绘制选择框，点击当前帧素材与时间线共享选择集，优先命中上层画面。四角支持绕中心等比例缩放，下方手柄旋转，画面内部拖动修改项目坐标；参数实时同步检查器，释放后复用一次保存/撤销事务。背景与前景共用该逻辑，边框按实际项目宽高比输出裁切，贴边手柄内收；隐藏、锁定、离线、音频及当前帧外片段不提供预览操作。
- 时间线元数据在释放手势时串行原子保存，索引失败回滚内存和项目；媒体探测/解码仍在后台。预览采用低分辨率软件合成，不代表最终导出分辨率或已验证的多轨实时性能。
- 最新 `.ref/轻线-状态图标4枚/qingxian-state-controls-4/svg` 中实际包含七枚 SVG，原样进入图标包：上下箭头、睁眼、闭眼、开锁、文本、低音量。清单 v1.7 共 102 枚；闭眼采用原始眼睑/睫毛造型。

- 新项目仅创建主轨，`TrackKind::{Main, Media, Audio, Subtitle}` 独立于显示名称，字幕类型保留但不默认建轨。主轨位于最下方；主轨与媒体轨道只接收图片、视频；音频拖入视觉轨道时在其上方自动创建音频轨道，音频轨道只接收音频。片段类型由导入探测结果明确传入并随项目保存，已有片段跨轨移动校验类型。所有片段按鼠标落点定位且可自由移动，空隙预览为黑画面。`timeline_edit.rs` 负责动态插轨、整体轨道重排与同轨不重叠约束：拖入、移动、裁边发生严格相交时，优先复用紧邻上方未锁定的同类型空轨道，否则新建相应类型轨道，首尾相接合法。清理在放置决定之后执行，删除全部空非主轨并重映射片段索引；即使为空也始终保留唯一主轨，载入项目同样清理空非主轨。旧三轨 V1 数据缺失类型时迁移空默认轨道并拆开旧重叠；新类型写入可选 V1 字段，索引统一重映射。
- 拖动片段的根层浮块保留按下偏移并在横纵方向随鼠标移动，行内显示最终落点，行间或上方空白显示插轨线，释放才应用片段移动和保存。通用设置“拖动素材时”提供“跟随鼠标”（默认，实际拖动时隐藏选中原块及把手）和“保留在时间线”（保留原块，浮块仍随鼠标移动）；仅影响绘制，支持多选，取消后恢复原块，不提前修改时间线模型或项目。选择先更新草稿，应用成功才发布并独立保存 `keep_dragged_clip` 用户偏好；旧偏好文件缺字段时默认跟随鼠标。轨道名称可拖动已有自由轨道调整层级，主轨固定最下方。轨道行高、命中、框选和竖向滚动范围均按实际轨道计算；插轨与片段放置属于同一历史事务。

- 库素材或已有单片段拖到同轨两个片段之间时，按实际落点至后一片段起点的剩余空隙与素材实际时长判断（库素材使用当前裁剪选区，移动片段使用自身时长）：足够或刚好放满时显示素材块并保留后续位置；不足时显示竖向插入线，按新片段时长后移全部后续片段并保留后续空隙。预览与提交共用 Core 的 `insertion_requires_shift`；相接边界使用 8px 帧容差，片段中部重叠仍按分轨规则处理。插入、空轨清理与后移属于单次保存和撤销事务。
- `timeline_scroll.rs` 为框选、片段和库素材拖动提供双向边缘滚动，播放头与裁边只横滚、轨道整体拖动只竖滚。唯一 16ms 定时任务使鼠标停在边缘时持续滚动；释放或离开边缘取消，框选和片段位移按滚动差保持内容锚点。横向可拖到当前屏外时间，竖向始终限制在实际轨道范围；Ctrl/Shift 加滚轮横向滚动，不改变缩放。
- 时间线最小缩放按所有轨道片段的最晚结束时间和当帧可见宽度自适应，包含片段前的空隙并预留 15% 尾部空间；空项目显示一分钟。滑块或缩小按钮到达最小档时回到时间零点全览，其余档对数插值到每秒 1800 像素。编辑手势按开始快照固定时长基准，释放后重新适配，避免裁边过程中比例漂移。

- `timeline_links.rs` 保存 `Clip.link` 可选关联 UUID，支持图片、视频和音频任意多段关联及旧组合并。关联不对齐时间、不修改源文件；点击、Ctrl/Shift 多选、框选和预览选择展开整组，Alt 临时单独选择或切割。工具栏复用既有“关联片段/解除关联”图标，关联组名称加下划线；至少两段且整组未锁定才可关联，同组重复关联禁用，解除作用于触及的完整组。联动移动保持相对时间，裁边复用单段规则并使用共同合法帧增量；插入后移展开后续关联成员，跨轨冲突或锁定时拒绝整次操作。切割后左右成员分别关联，单段右侧不保留关联；删除后自动清理单成员关联。保存与单次历史位于 `timeline_commit.rs`，V1 缺失 `link` 默认独立，非法 UUID 或单成员关联拒绝载入。

## 设置与快捷键

- `timeline_split.rs` 的 `Timeline::split` 按绝对项目帧切割指定集合中跨越该帧的未锁定片段；首尾、片段外和空选择无操作，两侧至少一帧。左段保留身份，右段复制源引用、变换和增益，音视频推进源入点，图片保持入点；校验失败原子回滚。`timeline_blade.rs` 处理桌面刀片命中及帧对齐虚线，仅命中片段或帧变化时通知重绘；`blade_cursor.rs` 在 Windows 使用 24px Razor 原生光标，使用 Inkscape 设计的独立实心双刃剃刀 `razor-cursor`，刀身短宽、四个端部缺口和中央短槽；时间线工具栏继续使用原始 `razor` 图标。左侧外刃中点为热点（100% DPI 下为 8,15），切割虚线和点击对齐刀刃而非图标中心。原生光标直接按 DPI 对应的整数设备像素栅格化，不放大旧位图；移动不依赖内容重绘，菜单、全屏和其他手势期间恢复系统指针。其他平台或原生创建失败使用系统十字光标，不绘制跟随鼠标的 SVG。刀片模式隐藏裁边把手，鼠标切割默认处理悬停素材及其关联成员，Alt 仅处理悬停单段。原先选中素材切开后两段保持选中；未选中素材直接切开后仍未选中。切割复用保存/回滚及单次撤销历史。
- 通用设置的“刀片切割模式”下拉提供“无需选中素材”（默认）与“需要选中素材”；后者未选中时不显示虚线，第一次点击仅选中，第二次点击切割。草稿应用后保存 `blade_requires_selection` 用户偏好，旧偏好文件默认直接切割，不写入项目。默认 `V` 选择工具、`C` 刀片工具、`Ctrl+B` 按播放头切割全部选中且跨越当前位置的未锁定素材；均纳入既有可重绑定快捷键注册表，输入框内不触发。播放头切割不依赖当前工具，鼠标刀片不移动播放头。

- `settings.rs` 管理独立非模态设置窗口、草稿与提交，`settings_view.rs` 绘制搜索/分类和控件；窗口内输入不会触发剪辑快捷键，切回编辑器仍可编辑。每个工作区复用一个设置窗口，工作区关闭时一并关闭辅助窗口。通用和语言/快捷键草稿经“应用”保存，项目页单独提交当前项目参数；关闭放弃未应用输入。
- `switch.rs` 提供通用受控 `Switch`：灰阶胶囊轨道和左右拨片，支持鼠标、Tab 聚焦及空格/Enter 切换，含悬停、按压和焦点样式。组件只回传目标布尔值；设置页负责修改草稿，“应用”后才持久化。
- `help.rs` 提供帮助菜单的“键盘快捷键”“关于”及关于窗口；使用编译版本、现有 Logo、官网“暂无”和用户指定的开源链接 `https://github.com/yan5236/dinuosi`。链接可能尚未公开，程序不探测仓库存在性。
- `shortcuts.rs` 集中定义操作 ID、标签、默认按键、覆盖读取、精确修饰键匹配、冲突检测和显示。用户录制替换该操作全部默认绑定，清除表示禁用，恢复默认移除覆盖；Escape、Tab、Enter、系统关闭组合保留。文本输入的编辑键不受工作区映射影响。
- Core `storage/preferences.rs` 在索引同目录原子保存 `preferences.json`（版本 1），包含实时拖动预览、语言与快捷键覆盖。Desktop `preferences.rs` 仅在写入成功后发布全局偏好；损坏/未来格式报告错误，不静默覆盖。插件运行时尚未实现，插件页显示空列表，不提供无效开关。
- Core `language.rs` 维护三个有效 ID：`auto`、`zh-CN`、`en`。自动选择使用 Desktop 已有依赖 `sys-locale` 读取系统首选语言；简体中文标签（含 Hans 脚本）使用 `zh-CN`，英文、不支持的系统语言及读取失败使用 `en`。繁体中文尚未支持。旧版偏好中的 `zh-TW`、`es`、`ru` 在载入时仅于内存迁移为 `en`，其余偏好保留，未知值或损坏版本仍报告错误。
- Desktop `i18n.rs` 编译内嵌 `locales/{en,zh-CN}/<module>.json`，按 common、manager、dialogs、editor、library、inspector、timeline、settings、help、icons 拆分；领域错误另外按 project、media、timeline 拆分。静态界面以英文源文或稳定 ID 为键，错误资源以 Core 既有消息模板为键，维持无 GUI 的错误合同。双语键集与占位符由测试检查，缺失/空译文回退英文。模板只替换一次，用户参数不会递归当作占位符。
- 已应用语言属于 GPUI 全局 `Locale`，偏好验证与原子写入成功后才发布；初始化、再次应用自动选择时解析系统语言。发布后刷新所有窗口，工作区、设置、关于及独立输入实体观察全局变化；辅助窗口同步更新原生标题。草稿选择不改变任何已应用文字；设置搜索匹配当前译文、中文设置词、语言 ID 和自称。项目名、素材别名与系统诊断保持原文，既有 Core 错误在界面展示边界翻译，不修改文件路径。
- 默认轨道名按轨道类型翻译。Core Track 和磁盘 TrackV1 增加 `custom_name` 标记：新轨道为 false，用户提交重命名后为 true，显式重命名成默认名也保留原文；旧文件缺失标记时按旧默认名推断，其他名称保持原文。
- Core `project_settings.rs` 校验分辨率 1–16384、整数帧率 1–240、码率 100–1000000 kbps；默认 1920×1080 / 30fps / 12000kbps。修改帧率时对绝对时间边界和源时间换算到新帧栅格，误差不超过半个新帧；如果片段消失、源范围越界或同轨重叠则拒绝并保留原项目。设置应用于最新编辑模型，保存失败不替换内存，成功记录一次撤销。项目 V1 新增可缺省的 `bitrate_kbps`，旧文件回退 12000；导出表单以项目参数为默认值，单次导出修改不写回项目，实际导出边界见 [EXPORT.md](EXPORT.md)。
- 媒体模型保留经旋转及像素比例修正的源尺寸。合成按项目坐标计算，小素材原尺寸居中补黑边，大素材等比缩小；手动变换仍有效。底层仍使用 640×360 解码/合成缓冲，显示时裁出项目比例对应的有效矩形，预览手柄和命中使用同一画布及素材尺寸。

## 参数关键帧与曲线

- Desktop `curve_panel.rs`、`curve_graph.rs`、`curve_edit.rs` 分别负责控件、画布和事务。工具栏菱形入口切换默认收起的独立面板，水平缩放、滚动范围和播放头与主时间线一致；打开时缩短上方区域，保留轨道操作空间。左侧属性选择拆分位置 X/Y 的显示，数据仍保持成组位置节点。唯一选中素材才可编辑，多选显示空网格；选择节点不移动播放头，空白画布用于寻址。
- 预设作用于选中节点后的区间，末节点使用前一区间；只修改当前分量和区间两侧切线。自由模式两侧独立，联动模式按真实左右帧间距同步斜率。节点可同时拖时间/数值，也可输入局部整数帧及精确数值（音量为 dB）；同类节点不交叉、不覆盖已有帧，锁定素材和轨道禁止修改。曲线内 Delete 删除该属性节点，时间线菱形仍删除同帧全部类型。
- 手势冻结按下模型和数值范围，移动只刷新预览，释放复用一次保存/回滚/撤销事务；Escape 取消拖动或数值草稿。在非线性区间记录新节点时用 De Casteljau 拆分相邻曲线，保留已有运动；自动改值继承拆分后的切线。切线横长使用相邻间距比例，裁剪、分割和换帧率保留同一动画定义。

- Core `keyframes.rs` 定义画面透明度、缩放、坐标、旋转及音频音量五类动画；坐标 X/Y 共用一组两分量关键帧。每项必须包含参数类型和有效数值，不存在空关键帧；`toggle_keyframe` 创建时直接记录当前静态值或插值。检查器空心菱形仅表示当前帧尚无该属性的关键帧。帧以片段起点为零保存；同帧可保存多类型，同类型同帧只能有一项。相邻关键帧缺省线性插值，可分别为每个分量保存贝塞尔入/出切线，首尾之外保持端点。Core `keyframe_curve.rs` 反解单调时间曲线再求值，过冲在共享求值入口夹紧业务范围；音量使用有限线性增益单位，PCM 对同一立体声采样对求同一增益；播放游标只前进，回调不分配或遍历全部关键帧。
- 检查器、合成画面、预览命中和拖动都使用当前项目帧求值。`set_property_at`、`set_volume_at` 接收播放头帧及自动添加偏好；当前已有帧直接修改，仅同类型已有动画且值实际改变时自动增加关键帧。未启用动画的类型仍修改静态参数。关闭自动添加后，帧间编辑以差值整体调整同类型动画并夹紧合法范围；已有帧上编辑只改该帧。动画素材在片段时间范围外不写入动画。
- Desktop `keyframes.rs` 绘制原有空心菱形与新增同形实心 SVG；仅唯一选中、与检查器类型匹配且覆盖当前播放头的素材显示按钮。两帧以上显示该类型前/后导航，直接跳转播放头；边界方向禁用。按钮支持鼠标、Tab、Enter、空格。增删复用项目保存、失败回滚和一次撤销。删除最后一项关键帧时保留当前值作为静态参数。
- 时间轴只在选中的素材块中绘制可见关键帧；同帧不同类型合并一枚实心菱形，取消选择隐藏。移动片段时动画随片段，裁剪和分割保留可见范围外插值锚点并调整局部帧，避免改变保留区间的动画。项目帧率变更按绝对时间换算关键帧；同类型不同帧若折叠为同一帧则拒绝整次设置，保持原项目。
- 磁盘 V1 以显式 `KeyframeV1 { frame, kind, values, curves }` 映射动画，旧项目缺关键帧字段默认空动画，缺 curves 时保持线性；未知类型、重复帧、非法时间/值及非有限、逆向或超长切线拒绝载入。用户偏好 `auto_keyframe` 默认开启，设置通用页通过既有 Switch 修改草稿，“应用”保存成功才发布；不写入项目。图标清单 v1.8 共 103 枚，新增 `keyframe-filled`；v1.9 共 104 枚，新增仅用于鼠标的实心 `razor-cursor`，由 Inkscape 1.4.4 生成路径，浅色刀身与深色轮廓分别保留。

- 坐标检查器的标签与 X/Y 分别使用独立占位，数值框恢复 59px 数值区及 17px 箭头。检查器宽度不足 360px 时 X/Y 成组竖排，标签及坐标关键帧控件各自保持完整，避免缩窄数值与粘连文字。
- `timeline_keyframes.rs` 在把手之上绘制 18px 命中区内的 12px 合并菱形，中心对齐真实项目帧，不再将首尾关键帧夹到片段内部。左键选择该素材并按帧寻址，右键打开仅含“删除关键帧”的既有灰阶菜单，不移动播放头。删除针对该素材在该帧的所有类型，其他素材和其他帧保留；复用 Core `remove_keyframes`、原子保存及一次撤销。菜单支持 Enter/空格、Escape、点击外部关闭，并隔离素材删除等工作区快捷键；画面/模型刷新关闭过期菜单，避免帧率变更后误用旧目标。

## 预览观看模式

- `preview_player.rs` 复用素材与时间线播放/寻址；普通预览左右按钮按项目帧率前后移动一帧并暂停，边界夹紧到最后有效帧。双语提示为“上一帧/下一帧”。
- 放大仅将预览画面作为原生全屏窗口内容，按比例完整显示并补黑边。观看布局不挂载编辑器、素材选择/变换手柄、裁剪条或菜单；底部提供进度拖动、播放/暂停与退出全屏，Escape 同样退出。全屏屏蔽剪辑快捷键；进度拖动暂停对应播放器并在释放后恢复拖动前的播放状态，仍遵循实时/释放预览偏好。退出保留播放位置、选择和项目数据。

- 静态寻址成功退出却未输出画面时（例如 24fps 源的最后时间戳早于 30fps 项目尾帧），Core 对源文件最后一秒顺序解码并保留最后一帧以取得真实尾帧；实际解码失败仍报告错误，正常寻址不增加解码或修改源文件。

## 磁吸、项目标记与片段锁定

- Core `timeline_tools.rs` 保存项目标记（稳定身份、绝对帧、名称、RGB）和磁吸开关；磁吸默认开启。共享 `snap_offset` 根据拟放置首尾到零点、播放头、全部标记及跨轨片段首尾的最近距离返回整组帧修正量，排除移动组自身。Desktop `timeline_snap.rs` 把 8px 容差映射为项目帧，库拖入、整组移动、裁边和落点提示共用同一规则；关闭磁吸仅保留正常帧取整。片段间插入依据拟放置首帧，保留鼠标按下偏移，预览和释放提交一致。
- `timeline_markers.rs` 接通工具栏在播放头添加标记，检查器“标记点”页签按时间排序，点击列表/刻度跳转，右键提供修改与删除。`marker_dialog.rs` 以现有灰阶模态表单编辑名称和颜色，确认才原子保存并记录一次历史，取消/关闭/Escape 放弃草稿，校验或保存失败保留表单及原模型。旗帜按原 SVG 的 x=5.5 竖杆中心对齐项目帧，不以包围盒中心对齐；标记竖线共用相同项目帧/滚动坐标，视觉层不建立鼠标命中区。无片段选择时 `inspector_overview.rs` 显示当前项目名称、分辨率、帧率、码率和时长。
- `Clip.locked` 独立于轨道锁；片段仍可点击、框选和在预览选中，检查器保留数值但禁止修改，预览只显示边框。核心保护移动、裁边、变换、音量、关键帧、切割和删除；插入需要后移锁定素材或重排含锁定素材的轨道时整次拒绝。再次点击工具栏解锁恢复编辑。
- 片段锁定、标记和磁吸以可缺省 V1 字段原子保存；旧项目默认无标记、片段解锁、磁吸开启。标记时间随项目帧率换算；全部编辑沿用一次保存/回滚和撤销/重做。撤销移除片段后清除失效选择，使检查器回到项目资料。

- 用户偏好 `show_marker_lines` 通过通用设置草稿及“应用”独立原子保存，默认和旧文件缺字段时为 false；切换显示不创建项目历史，不影响标记磁吸。

## 受控媒体发行边界

Core 通过独立 `crates/media` 从本进程目录下的 runtime/ffmpeg 加载原生桥接库，直接调用 libav，不创建媒体子进程或回退 PATH；开发与测试部署同一套动态库。Rust unsafe 与 C ABI 仅限此边界，上下文独占，Core/Desktop 保持 safe Rust。FFmpeg 8.0.3 使用可替换动态 libav 库，zlib 和 LGPL LAME 从固定源码构建；兼容补丁、构建参数与原始归档随对应源码包保存。主程序静态链接 Windows C 运行库，媒体算法和既有项目格式不变。

准备、封存、许可收集与打包分别位于 tools/，所有下载输入由 distribution/inputs.lock.json 验证。音源大文件、外部工具和构建产物不进入 Git。打包校验运行时及许可文件哈希、原始源码和补丁一致性；元数据中的双许可只选择允许分支，不擅自重授第三方版权。原始完整许可缺失的五个旧包附真实声明、完整源码及标准文本，明确保留公开发布审查项。

NSIS 安装和便携版使用同一应用文件清单。安装写当前用户的应用目录、开始菜单和卸载登记；交互完成页可按勾选创建桌面快捷方式及启动程序，静默安装跳过这些完成页操作。卸载按清单删除文件并非递归移除目录，仅在安装登记表明本安装器创建过桌面快捷方式时删除它，保留未知文件及用户数据。安装语言与应用语言偏好分离；关于窗口通过本地文件提供第三方声明，不联网。

Windows 静态 C 运行库代码按 Visual Studio/Build Tools 的再分发条款分别管理，不因 FFmpeg 的 LGPL 改变其许可；不把 Windows 系统 DLL 打入安装包。公开发布前核对适用条款和主程序许可，不能把内部验收结果视为法律意见。

## 时间线导出

Core `export.rs` 提供无 GUI 的能力检测、参数校验与阻塞导出接口；`export_render.rs` 顺序解码原显示尺寸 BGRA，并复用 `composite::blend_pixels` 的轨道混合、画布适配与变换。画面使用片段源入点、隐藏轨道及画面关键帧；声音复用 `TimelineAudio`，保留空隙、源选区、静音、增益和音量关键帧（包含 MIDI）。不同输出帧率按输出时间选取当前项目帧，关键帧仍按时间插值，不改写项目。

Desktop `export_dialog.rs` 管理唯一模态任务，`export_view.rs` 绘制项目预览和任务状态，`export_controls.rs` 处理参数与下拉交互。后台处理不可变时间线快照，主线程只轮询原子进度；参数及文件夹选择不写入项目。取消或窗口销毁设置原子标志并回收本次原生解码/编码会话。`export_cancel.rs` 以弱引用登记稳定取消句柄，原生错误通过返回值发布；专属临时目录保存 PCM 和待发布视频，成功后无覆盖发布，失败清理。参与导出的离线源会失败，已有输出保持原样。

受控 FFmpeg 通过 Windows Media Foundation、macOS VideoToolbox 和 Unix OpenH264 软件路径提供 H.264；不启用 GPL/nonfree/version3，不加入 libx264 或系统 PATH 的 FFmpeg。`Encoder::candidates` 只返回本平台候选，能力检测实际试编码后才加入选项；有可用硬件时优先选择硬件以降低 CPU 占用。MP4/MKV 均配 AAC，系统或硬件实现是否可用由本机检测与实际编码结果决定。运行库定位、原生构建和桌面平台约定见 [跨平台支持](CROSS_PLATFORM.md)。

AV1/VP9 分别由可替换 libavcodec 中的 BSD libaom/libvpx 提供，不静态链接进 Rust 主程序。MIT 桥接库与对应源码一起封存。固定源码、许可及专利原文纳入同一封存/重建/打包链路。能力检测结果在进程内缓存；导出进度变化才刷新界面，源画面和合成输出缓冲在导出会话内复用。
