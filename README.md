# Dinuosi · 迪诺斯

本地优先的开源视频剪辑软件，采用 Rust + GPUI。产品目标见 [docs/RPD.md](docs/RPD.md)，原有架构说明见 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)；本地界面参考图位于 `.ref/`，不进入版本控制。下文记录当前实际能力与本轮存储边界。

## 开发

Windows 开发环境需 Rust stable（MSVC）、Visual Studio C++ Build Tools 和 Windows SDK。GPUI 固定为 0.2.2；应用依赖锁定在 Cargo.lock 中。其他平台的系统依赖参见 [GPUI 文档](https://docs.rs/gpui/0.2.2/gpui/)。

```powershell
cargo run -p dinuosi-desktop
cargo fmt --all -- --check
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace
```

首次构建需要联网下载依赖；图标、Logo 和 MIDI GM 音源已嵌入程序，运行不依赖原始素材目录。普通媒体预览需要 `ffmpeg` 和 `ffprobe`，优先读取程序同目录中的可执行文件，其次读取 PATH。标准 `.mid`/`.midi` 使用 RustySynth 与 TimGM6mb 乐器采样库，无需配置音源，不经过 ModPlug；输出同样为立体声 48kHz，由 Rodio 连接默认设备。音源原始署名和 GPL-2 许可见 `assets/audio/`。仅验证非 GUI 模块可运行 `cargo test -p dinuosi-core -p dinuosi-command -p dinuosi-icons`。

## 初始化范围

- `apps/desktop`：GPUI 项目管理、原生项目表单、独立剪辑窗口、引用式素材库与实时媒体预览。
- `crates/core`：项目身份、名称校验、版本化文件与最近项目索引，以及媒体类型/时长探测、帧提取、流式 BGRA/PCM 解码和离线检查；不依赖 GPUI 或音频设备，可供 CLI 复用。
- `crates/command`：共享的创建、打开、重命名与删除项目命令入口，可独立于 GUI 执行。
- `crates/icons`：轻线 v1.7 的 102 枚 SVG（含分类、播放头、媒体离线和状态控件）、清单，以及构建生成的 `Icon` 枚举。所有界面 SVG 先进入此包，再通过枚举使用。
- `assets/brand`：Logo PNG 导出文件与可编辑 SVG 原稿。

项目管理窗口固定为 900×620 逻辑像素，在系统层禁止调整大小和最大化，左下角不显示项目计数或额外状态文字。剪辑窗口默认 1440×900，最小 1040×640，并保留原有三栏、时间线比例、中性灰与轻线图标。

界面遵守 [AGENTS.md](AGENTS.md)：仅完成明确任务与必要部分，不自行添加功能、入口、副标题、描述性文本或额外信息；导出左侧不显示项目名称。表单只保留控件名称、要求的删除确认与勾选项、实际错误反馈。

新建先弹出项目名称和目录表单，通过系统目录选择器选择父目录，再在其中创建独立项目文件夹。创建成功或打开已有项目时，先创建独立剪辑窗口，再关闭管理窗口；关闭剪辑窗口或点击 Logo/Ctrl+H 会重新创建管理窗口。关闭管理窗口退出应用。

项目列表支持重新打开、更多菜单重命名及删除。重命名更新显示名称并保留目录和 UUID。删除弹窗默认仅从列表移除；显式勾选后才删除带匹配所有权标记的项目文件夹，不删除外部引用的素材。无标记的导入目录只允许从列表移除。被移除但保留文件的项目可用“打开项目”重新登记。

Ctrl+N 新建，Ctrl+O 打开项目；表单支持中文 IME、选择、剪贴板、Tab、Enter 与 Escape。文件菜单支持多选“导入素材”，也可把文件从资源管理器拖入素材库。素材按全部、视频、音频、图片、动效、特效分类，支持文件名搜索；动效和特效目前没有对应素材。导入只保存源文件路径，不复制媒体。视频显示首帧缩略图，选择素材后可看图、播放视频或听音频，拖动播放头和两端把手设置预览范围；音量及标尺缩放均可拖动。图片默认预览长度五秒。未选择素材时不显示“添加至轨道”；选择后可点击添加，或把素材缩略图直接拖入媒体轨道/主轨。刀片分割及导出仍未实现。

引用文件改名、移动或删除后，素材条目保留，素材库和选中素材预览显示暗红背景、三角感叹号与“媒体离线”；运行中每秒检查一次源路径。重新打开项目也保留离线引用。原文件回到原路径后重新探测恢复，不自动扫描其他目录或重新链接同名文件。

素材卡片右键支持重命名和移除素材。重命名保存库内别名，保留源文件路径和文件名；移除只删除项目引用，不删除原文件。离线素材同样可操作，重新打开及源文件恢复后保留别名。移除正在预览的素材会停止播放并清空预览。

画面按素材显示比例完整居中，四周间距随预览面板变化；解码透明补边在桌面适配时移除，额外留白使用面板灰色，不生成黑边，也不去除源画面已有黑色内容。裁剪条位置使用实际轨道宽度，手柄覆盖边框与播放线。

### 时间线与检查器

时间线采用独立的字幕、媒体、主轨区域，浅灰背景区分轨道。标尺按缩放选择分秒/帧刻度，最大缩放每帧短线、每两帧标注；横向滚动同步刻度与片段，竖向滚动同步轨道头和内容。空白拖动可框选，Ctrl/Shift 追加选择，片段支持整组移动与两端裁边。Delete 或垃圾桶删除选中片段，Ctrl+Z / Ctrl+Shift+Z（或 Ctrl+Y）撤销/重做。锁定轨道不能编辑，眼睛和声音图标控制视频可见及音频静音。

检查器对选中片段提供不透明度 0–100%、缩放 0–500%、项目画布中心原点的 X/Y 像素坐标和 -360°–360° 旋转。滑块、数值输入和上下微调均修改真实核心参数并更新合成预览；一次拖动对应一次历史。时间线以整数帧/帧率表示时间，默认 30fps、1920×1080 画布，预览仍采用 640×360 BGRA 缓冲，并按项目比例裁切显示。

帮助菜单提供键盘快捷键和关于。剪辑界面通过“文件 → 设置”打开通用设置，重复点击复用已有窗口。设置使用独立窗口，编辑器仍可操作；通用、键盘快捷键、语言、插件及项目主要设置通过搜索定位。快捷键可录制、清除、恢复默认并在应用后持久化。项目支持主轨分辨率、整数帧率与码率，帧率更改保留片段秒数并吸附新帧栅格，小素材居中补黑边。语言页提供自动选择、简体中文和 English；选择只改草稿，应用成功后保存并刷新全部已打开窗口。自动选择按系统首选语言解析，未支持的语言或系统读取失败使用英文；缺失译文也回退英文。翻译按模块放在 `apps/desktop/locales/{en,zh-CN}/`，编译内嵌。项目/素材名称及用户重命名的轨道名保持原文，默认轨道名随界面语言变化。旧版保存的繁体中文、西班牙语、俄语选择在载入时迁移为英文，保留其他偏好。插件页当前为空；码率已保存，导出尚未实现。

播放头默认在拖动过程中连续预览。`ScrubPreview::Live` / `OnRelease` 是已保留的宿主设置接口，备用模式只在释放后更新；本轮不添加设置窗口。该偏好属于会话而非项目内容。素材库移除不删除源文件或已放入时间线的片段引用。

### 持久化格式

项目文件为新建目录内的 `project.dinuosi`，使用显式 `ProjectFormatV1` JSON 契约：`format: dinuosi-project`、`version: 1`、稳定 UUID、名称、UTC Unix 秒级创建/修改时间，以及可选的 `timeline`（帧率、画布、轨道、稳定片段 ID、源选区和变换）、`media_paths` 源文件绝对路径列表和 `media_names` 路径到显示别名的映射（旧项目默认空集合）。加载时校验格式、版本与字段，拒绝损坏或未知版本；内部领域模型不直接序列化。剪辑缩放、音量、预览选区和窗口状态不写入项目。

Windows 最近项目索引位于 `%LOCALAPPDATA%/Dinuosi/recent-projects.json`；开发或测试可通过 `DINUOSI_DATA_DIR` 指定独立数据目录。项目与索引使用同目录临时文件刷盘后原子替换；重命名/删除的索引写入失败会恢复项目文件/目录。损坏索引会显示错误，绝不静默重置为空列表。目录删除最终清理失败会报告隔离目录位置，便于找回残余文件。

## 架构与后续开发

GUI 负责窗口、布局、输入与会话；项目业务经 Command 进入 Core，磁盘操作在后台执行。Desktop 的 `windows.rs` 管理窗口生命周期，`manager.rs` 管理列表，`dialogs.rs` 管理表单，`input.rs` 处理原生输入，`editor.rs` 保留剪辑布局，`view.rs` 调度命令。`library.rs` 负责素材库，`media.rs` 只适配 Core 的媒体模型和 GPUI 图像，`playback.rs` 只适配 Core 解码流、Rodio 设备和播放时钟，`preview.rs` 与 `preview_view.rs` 分别负责预览会话与控件绘制，`sliders.rs` 负责指针交互，`media_status.rs` 调度核心离线检查并绘制状态。核心包的 `media.rs` 和 `media_stream.rs` 提供与 GUI 无关的媒体处理 API。时间线编辑、历史、像素合成与音频混合位于 Core；Desktop 仅负责窗口输入、绘制、后台调度和设备输出。后续再实现刀片分割及导出。图标按 `crates/icons/spec.json` 生成，修改清单或 SVG 后 Cargo 自动重新构建，不应手工维护生成文件。

软件及素材的公开发布许可证待确认，当前所有 package 均禁止发布到 crates.io；没有为用户素材擅自指定许可证。
