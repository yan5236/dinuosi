# Dinuosi · 迪诺斯

本地优先的开源视频剪辑软件，采用 Rust + GPUI。产品目标见 [docs/RPD.md](docs/RPD.md)，原有架构说明见 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)；本地界面参考图位于 `.ref/`，不进入版本控制。下文记录当前实际能力与本轮存储边界。

## 开发

Windows 开发环境需 Rust stable（MSVC）、Visual Studio C++ Build Tools 和 Windows SDK。GPUI 固定为 0.2.2；应用依赖锁定在 Cargo.lock 中。其他平台的系统依赖参见 [GPUI 文档](https://docs.rs/gpui/0.2.2/gpui/)。

```powershell
cargo run -p dinuosi-desktop
cargo fmt --all -- --check
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace
```

首次构建需要联网下载依赖；图标和界面 Logo 已嵌入程序，运行不依赖原始素材目录。仅验证非 GUI 模块可运行 `cargo test -p dinuosi-core -p dinuosi-command -p dinuosi-icons`。

## 初始化范围

- `apps/desktop`：GPUI 项目管理、原生项目表单、独立剪辑窗口与空编辑工作区。
- `crates/core`：项目身份、名称校验、版本化文件与最近项目索引；不依赖 GPUI。
- `crates/command`：共享的创建、打开、重命名与删除项目命令入口，可独立于 GUI 执行。
- `crates/icons`：轻线 v1.5 的 89 枚原始 SVG、清单、说明，以及构建生成的 `Icon` 枚举。
- `assets/brand`：Logo PNG 导出文件与可编辑 SVG 原稿。

项目管理窗口固定为 900×620 逻辑像素，在系统层禁止调整大小和最大化，左下角不显示项目计数或额外状态文字。剪辑窗口默认 1440×900，最小 1040×640，并保留原有三栏、时间线比例、中性灰与轻线图标。

界面遵守 [AGENTS.md](AGENTS.md)：仅完成明确任务与必要部分，不自行添加功能、入口、副标题、描述性文本或额外信息；导出左侧不显示项目名称。表单只保留控件名称、要求的删除确认与勾选项、实际错误反馈。

新建先弹出项目名称和目录表单，通过系统目录选择器选择父目录，再在其中创建独立项目文件夹。创建成功或打开已有项目时，先创建独立剪辑窗口，再关闭管理窗口；关闭剪辑窗口或点击 Logo/Ctrl+H 会重新创建管理窗口。关闭管理窗口退出应用。

项目列表支持重新打开、更多菜单重命名及删除。重命名更新显示名称并保留目录和 UUID。删除弹窗默认仅从列表移除；显式勾选后才删除带匹配所有权标记的项目文件夹，不删除外部引用的素材。无标记的导入目录只允许从列表移除。被移除但保留文件的项目可用“打开项目”重新登记。

Ctrl+N 新建，Ctrl+O 打开项目；表单支持中文 IME、选择、剪贴板、Tab、Enter 与 Escape。设置、时间线编辑、媒体预览和导出尚未实现，对应入口提示或置灰；当前保存的是空项目身份及元数据，未宣称已支持媒体或时间线内容。没有引入 FFmpeg、AI 或插件运行时。

### 持久化格式

项目文件为新建目录内的 `project.dinuosi`，使用显式 `ProjectFormatV1` JSON 契约：`format: dinuosi-project`、`version: 1`、稳定 UUID、名称及 UTC Unix 秒级创建/修改时间。加载时校验格式、版本与字段，拒绝损坏或未知版本；内部领域模型不直接序列化。剪辑缩放、音量和窗口状态不写入项目。

Windows 最近项目索引位于 `%LOCALAPPDATA%/Dinuosi/recent-projects.json`；开发或测试可通过 `DINUOSI_DATA_DIR` 指定独立数据目录。项目与索引使用同目录临时文件刷盘后原子替换；重命名/删除的索引写入失败会恢复项目文件/目录。损坏索引会显示错误，绝不静默重置为空列表。目录删除最终清理失败会报告隔离目录位置，便于找回残余文件。

## 架构与后续开发

GUI 负责窗口、布局、输入与会话；项目业务经 Command 进入 Core，磁盘操作在后台执行。Desktop 的 `windows.rs` 管理窗口生命周期，`manager.rs` 管理列表，`dialogs.rs` 管理表单，`input.rs` 处理原生输入，`editor.rs` 保留剪辑布局，`view.rs` 调度命令并呈现结果。下一阶段再实现时间线、Undo/Redo、媒体导入、预览与导出。图标按 `crates/icons/spec.json` 生成，修改清单或 SVG 后 Cargo 自动重新构建，不应手工维护生成文件。

软件及素材的公开发布许可证待确认，当前所有 package 均禁止发布到 crates.io；没有为用户素材擅自指定许可证。
